# 净影去水印 · ClearMark Studio

纯浏览器本地运行的 AI 图片无痕去水印工作台。所有图像处理与神经网络推理均在本地完成，图片**零上传**、非遮罩区域**像素级无损保留**、保持原图分辨率导出。

---

## 核心特性

### 1. 三引擎协同修复

根据水印类型与背景复杂度，可在顶栏自由切换三套本地修复引擎：

| 引擎                     | 默认状态            | 技术方案                                                                                                                                                             | 适用场景                                                |
| ------------------------ | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| **快速修复（Fast）**     | 默认 · 零下载       | Web Worker + Telea Fast Marching + 拉普拉斯调和融合（`∇²I = 0`）+ 半透明逆向还原与高频微纹理回填，提供标准 / 精细两档质量                                            | 即梦、可灵、豆包等角落文字/图标水印，毫秒级无马赛克去除 |
| **AI 精修（MI-GAN v2）** | 随站内置 · 离线即用 | 内置 28.1 MB `migan_pipeline_v2.onnx`，独立 Web Worker 通过 `onnxruntime-web/wasm` 推理（无需 COOP/COEP），轻量预填后分簇截取 `512×512` 窗口高清重构                 | 手动框选大面积不透明水印、复杂人物/建筑/自然纹理背景    |
| **高阶 AI（LaMa ONNX）** | 按需下载或本地导入  | 约 208 MB Big-LaMa `512×512` ONNX 权重，持久化缓存于 IndexedDB；优先使用 **WebGPU** 硬件加速，异常自动回退 WASM，采用 Crop-and-Stitch 局部裁剪拼接保持 4K 原图分辨率 | 超大面积遮挡、需要更强全局结构补全的高难场景            |

### 2. 智能水印识别与选区精修

- **双轨角落水印自动检测**：
  - **精准模板匹配**：内置「即梦AI」「可灵AI」「可灵AI 3.0」「豆包AI生成」真实 Alpha 笔画模板，支持四角扫描、多尺度与亚像素匹配、亮/暗双极性识别及多角同时检出，直接生成紧贴笔画的细窄遮罩。
  - **通用形态学兜底**：未命中已知平台模板时，自动通过灰度白/黑顶帽（Top-Hat）与连通域文字行聚类探测未知角落文字水印，支持低 / 中 / 高三档灵敏度。
- **一键智能抠笔画（Smart Stroke Refinement）**：将实心矩形框或粗涂抹选区自动收缩为紧贴文字/图标笔画的细遮罩，最大限度保留字缝间的原始背景纹理。
- **平台预设与自定义预设**：内置即梦 AI、可灵 AI、豆包 AI、通义万相及通用四角共 12 套预设（含双角水印），按画幅比例（16:9 / 1:1 / 9:16 等）自适应计算区域；支持在画布拖拽微调并保存为持久化自定义预设（`localStorage`）。

### 3. 专业修图画布与批量工作流

- **多样化导入与开箱体验**：支持点击选择、全局拖拽、剪贴板粘贴（`Ctrl/⌘ + V`），兼容 PNG / JPG / WebP / BMP / GIF / AVIF；内置 3 张程序化生成演示样图，无需找图即可直接体验单张与批量处理。
- **完整修图工具集**：画笔涂抹（4–200 px）、矩形框选、橡皮擦、预设框微调、抓手平移；支持选区膨胀、遮罩透明度与显隐控制、边缘羽化（0–16 px）。
- **直观对比与独立历史栈**：支持分屏对比滑杆及按住 `\` 瞬时对比原图；队列中每张图片维护独立撤销/重做历史（最多 20 步，始终保留原图节点）。
- **多图批量队列与灵活导出**：
  - 支持批量套用预设、批量应用当前选区、全队列一键检测、顺序批量去水印及中途取消。
  - 原分辨率导出 PNG（无损，保留透明通道）、JPEG、WebP（可调质量 0.1–1.0），支持自定义文件名后缀（默认 `_clean`）、通过 Canvas 重编码剥离 EXIF 与 AIGC 元信息、一键复制无损 PNG 至剪贴板，以及批量打包下载 ZIP。
- **双色专业主题**：支持暗色 / 浅色界面切换并自动记忆偏好。

## 技术栈

- **前端框架**：React 19 + TypeScript 5.8 + Vite 6
- **样式与图标**：Tailwind CSS 4（`@tailwindcss/vite`）+ Lucide React
- **本地 AI 推理与存储**：ONNX Runtime Web（`onnxruntime-web`，WASM / WebGPU）、Web Workers、IndexedDB
- **打包导出**：JSZip
- **测试与代码规范**：Vitest 5（jsdom）、ESLint 9、Prettier 3

## 快速开始

### 环境要求

- **Node.js**：18+（推荐使用 Node.js 20 LTS 及以上）
- **浏览器**：现代 Chromium / Firefox / Safari 浏览器；如需体验 LaMa 的 WebGPU 硬件加速，建议使用支持 WebGPU 的 Chrome / Edge 桌面端浏览器。

### 安装与运行

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器
```

## 使用指南

1. **导入图片**：拖放图片到窗口、点击「导入图片」、按 `Ctrl/⌘ + V` 粘贴剪贴板图片，或在右上角「体验示例图」菜单中载入内置样图。
2. **标记水印区域**：
   - 角落水印：点击右侧面板「智能检测」自动识别并生成笔画级遮罩，或直接套用对应平台预设（支持画布微调）。
   - 任意位置水印：使用画笔（`B`）涂抹或矩形（`R`）框选；框选文字水印后可点击「紧贴笔画」收窄选区。
3. **选择引擎并执行修复**：
   - 常规角落水印推荐保持默认的 **快速修复**，毫秒级完成且保留字缝细节。
   - 大面积不透明遮挡或复杂纹理背景，可切换顶栏 **AI 精修（MI-GAN）**。
   - 如需更大尺度结构补全，点击顶栏模型管理图标，在线下载（推荐内置 HF-Mirror 国内镜像）或拖拽导入本地 `.onnx` 文件启用 **LaMa** 引擎。
4. **对比与导出**：拖动分屏滑杆或按住 `\` 核对修复前后效果；确认无误后单张导出、复制到剪贴板，或在底部队列栏一键打包 ZIP。

## 模型许可与隐私说明

- **本地零上传**：所有图片解码、遮罩计算、去水印推理与导出打包均在您的浏览器本地执行，不会向任何服务器上传图片数据。
- **内置 MI-GAN 模型**：随仓库附带的 `src/assets/migan_pipeline_v2.onnx`（约 28.1 MB）来自 Picsart AI Research (PAIR) 的 MI-GAN 项目，遵循 MIT 许可证，详见 [public/vendor/MI-GAN-LICENSE.txt](public/vendor/MI-GAN-LICENSE.txt)。
- **可选 LaMa 模型**：LaMa ONNX 权重不随本仓库分发，需由用户在「AI 模型管理」弹窗中按需从公开仓库在线下载或手动导入本地 `.onnx` 文件，并仅存储于当前浏览器的 IndexedDB 中。
